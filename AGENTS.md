# Agent instructions

Before changing or executing a release, read `docs/release-process.md`. New
crates require one initial crates.io allocation before GitHub Trusted
Publishing can be configured; do not introduce a long-lived registry token.

Knowledge Base owns article, revision, publication, and idempotency facts only.
Organization membership, RBAC, identity, secrets, and the rebuildable Search
index remain in their owner Plugins.
